What happens at each step

1. Bring workloads Portfolio inventory
Connect application repositories and branches to Tanzu Platform.
2. Assess Assessment report
Analyze frameworks, dependencies, deployment model, and cloud-readiness signals.
3. Discover debt Prioritized findings
Classify findings as auto-fix (a deterministic change applied by the CLI), AI-assisted (an agent-guided rewrite), or manual (a human decision and implementation).
4. Onboard Manifest + plan
Run /tanzu-onboard to verify prerequisites, generate deployment metadata, and obtain advice.
5. AI-assisted modernization Boot 4 app
Use the AI agent with /tanzu-onboard for platform readiness and /tanzu-modernize-app to extract behavior, select stories, rewrite to Boot 4, and generate tests.
6. Optimize & prove Tested JAR
Apply Tanzu starter, AOT, and Git metadata advice; then build and run compatibility tests.
7. Push Running app
Deploy with the generated manifest, validate health, and exercise the business endpoint.
Core sequence /tanzu-onboard establishes platform readiness. AI-assisted /tanzu-modernize-app orchestrates discovery, story extraction, Spring Boot rewriting, and tests. Tanzu advice applies platform conventions before build and deployment.

Is it worth it?

Strong fit Multiple applications, mixed teams, repeatable governance, auditable decisions, consistent testing, or Tanzu deployment standards. The value compounds across the portfolio.
Smaller advantage A single tiny application handled by an expert who only needs a code conversion. Plain AI may be sufficient when repeatability, platform alignment, and traceability are not priorities.
